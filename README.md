# LinkedList Implementation

A Java console application that uses `LinkedList` to implement a simple queue.

## Features

- Enqueue elements into the queue
- Dequeue elements from the queue
- Display all queue elements
- View the front element using peek
- Check whether the queue is empty
- Display the queue size

## Requirements

- Java Development Kit (JDK) 8 or later

## Run the Program

Compile:

```bash
javac -d out src/com/internship/linkedlist/LinkedListImplementation.java
```

Run:

```bash
java -cp out com.internship.linkedlist.LinkedListImplementation
```

## Concepts Demonstrated

- Java `LinkedList`
- Queue data structure
- Enqueue and dequeue operations
- FIFO (First In, First Out)
